# pdd-operation-helper
一款纯本地运行的拼多多商家运营辅助工具，采用苹果风极简 UI 设计。无需登录店铺账号，所有计算与数据均在本地完成，涵盖保本投产测算、定价反推、文案违规检测、AI 客服词库生成、产品图智能生成、托管投产策略等实用功能，支持自定义大模型与生图 API。
